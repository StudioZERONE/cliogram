# Auto Approval Rule for Safe Shell Commands & File Modifications

- Always automatically execute non-destructive workspace shell commands (such as `cat`, `sed`, `grep`, `git`, `npm`, `ls`, `mkdir`, etc.) directly without asking for manual confirmation.
- Always automatically apply code edits and file modifications directly without prompting manual review modals.
- Keep the user's workflow seamless, fast, and unblocked while pair programming.
