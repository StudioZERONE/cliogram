### 1.2 지식 문서 관리 체계 수립 (Vault Document Conventions)

### 1.3 데이터베이스 및 RLS 삼중 SQL 아키텍처 유지

- 비공개 샘플 마이그레이션 `sql/c_data_migration.sql` 구조 점검.

### 1.4 모바일 브라우저 동적 툴바 대응 (`100dvh` & Safe Area Inset)
- 모바일(iOS Safari/Chrome) 브라우저 하단 툴바 활성화 시 사이드바 하단 메뉴가 가려지는 현상 수정.
- `h-[100dvh]` 및 `pb-[calc(1rem+env(safe-area-inset-bottom,0px))]` 적용으로 스크롤에 따른 툴바 변화 시 사이드바 하단 메뉴가 자연스럽게 상단 여백을 유지하며 밀착되도록 반응형 조절.

### 1.5 환율 인디케이터 표기 표준화 (`KRW/USD`)
- 상단 헤더(Header)의 환율 표시 텍스트를 `USD/KRW:`에서 표준 통화 표기인 `KRW/USD:`로 수정 완료.

### 1.6 출근/퇴근 생명주기 기반 개발 서버 자동화 정책 정립 (Work Lifecycle & Auto Dev Server)
- 개발자의 출근 인사("출근", "나 왔어", "일 시작하자", "좋은 하루~") 시 `http://localhost:3000` 로컬 개발 서버를 자동 가동.
- 코드 커밋 후 개발 서버 상태를 신선하게 자동 재가동/유지.
- 퇴근 인사("퇴근하자", "오늘은 여기까지", "수고했다") 시 개발 서버 프로세스(`lsof -ti :3000`)를 자동 종료하고 세션 완결.
- 새벽/야근 시 모호할 경우 질문 확인 후 연속 야근 처리 규칙 도입.
- `GEMINI.md` 제5조 6항 및 Obsidian Vault 규칙 문서(`21.01`, `21.03`) 반영 완료.

### 1.7 공통코드 기능 고도화 및 엄격한 DB 마스터 진실 원칙 정립 (Strict DB Truth Principle)
- 공통코드 및 상세코드 관리 기능(`app/codes/page.tsx`) 고도화 완료 (모달 UI 기반 추가/수정, 마우스 드래그 앤 드롭 정렬, 그룹 실시간 검색/정렬, 모바일 마스터-디테일 반응형 뷰).
- **엄격한 DB 마스터 진실 원칙 정립**:
  - 임시용 가짜 덤미 데이터(`FALLBACK_CODES`) 및 조용한 자동 매핑(`CURRENCY` -> `CURRENCY_CODE`)을 코드에서 전면 제거.
  - DB 데이터 미설정이나 잘못된 인자 전달 시 이를 조용하게 감추지 않고, DB의 실시간 상태(`[]` 빈 배열)만을 직관적으로 직접 표출하도록 공통코드 조회 모듈(`lib/codes.ts`, `CodeSelect.tsx`)을 정제.
  - 해당 아키텍처 철학을 프로젝트 헌법(`GEMINI.md` 제5조 7항) 및 Obsidian Vault 규정 문서(`21.03.코드 구현 및 개발 교정 컨벤션.md`)에 공식 보관 등록.
